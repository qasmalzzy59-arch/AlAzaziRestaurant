# مطعم ومخبازة وشواية العزعزي

موقع إلكتروني عربي احترافي متجاوب (RTL) لمطعم ومخبازة وشواية العزعزي، مبني باستخدام **HTML5** و **CSS3** و **JavaScript** حديث بدون مكتبات خارجية، ويعمل مباشرة بفتح `index.html` في المتصفح.

تم ضبط التباين وسيطة القراءة للنصوص والأسعار والنماذج على اللابتوب والجوال، مع دعم كامل لاتجاه RTL وخطي Cairo و Tajawal.

## إضافة صور حقيقية لاحقاً

يدعم كل صنف صورة اختيارية من مجلد `images/` دون أي تعديل على التصميم:

1. ضع الصورة داخل مجلد `images/` بنفس اسم الملف المذكور في خاصية `img` للصنف.
2. أسماء الملفات المتوقعة موضحة في [`images/README.md`](images/README.md).
3. إذا لم توجد الصورة أو تعذر تحميلها، تظهر أيقونة الصنف داخل بطاقة نظيفة تلقائياً — فلا تظهر صور مكسورة.

## المميزات

- واجهة عربية RTL متجاوبة بالكامل مع الجوال والتابلت واللابتوب، وبطاقات وأزرار مرتبة دون خروج عن الشاشة.
- قائمة طعام تفاعلية: بحث فوري، فلاتر للتصنيفات الأربعة، وعداد كمية لكل صنف.
- سلة طلبات جانبية تحسب الإجمالي تلقائياً بعملة الريال اليمني دون ضريبة.
- إرسال الطلب مباشرة إلى واتساب المطعم (967777698379) مع تفاصيل الأصناف والإجمالي وطريقة الاستلام.
- نموذج حجز طاولة (الاسم، الجوال، التاريخ، الوقت، عدد الأشخاص، ملاحظة) مع تحقق من البيانات، وتأكيد فوري، وإرسال تفاصيل الحجز عبر واتساب.
- قسم مميزات، قسم "من نحن"، وبيانات تواصل كاملة مع رابط الخريطة.
- تذييل يضم بيانات المطعم وبيانات المطور، وزر العودة إلى الأعلى، وإشعارات Toast.
- تصميم نظيف بأيقونات SVG مدمجة، وألوان عالية التباين، دون أي صور أجنبية أو غير مطابقة.

## كيفية التشغيل

1. افتح `index.html` بأي متصفح حديث (Chrome، Edge، Firefox، Safari).
2. لا يحتاج الموقع إلى خادم محلي، ويعمل مباشرة من الملف.
3. للتحقق من صحة جافاسكريبت: `node --check js/app.js`.

## تخصيص البيانات

- **رقم واتساب الطلبات:** `js/app.js` → `CONFIG.WHATSAPP`
- **عنوان المطعم:** `js/app.js` → `CONFIG.ADDRESS`
- **أرقام الهاتف:** `js/app.js` → `CONFIG.PHONES` وفي أقسام الاتصال بـ `index.html`
- **قائمة الطعام والأسعار:** `js/app.js` → `MENU` (أضف/عدّل `price` فقط، مع الحفاظ على الأصناف الاثني عشر المطلوبة)
- **الصور:** ملفات `images/` حسب الأسماء الموضحة في `images/README.md`
