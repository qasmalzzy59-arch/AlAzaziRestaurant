## ملاحظات

- لا حاجة لتعديل الكود: التصميم يقرأ المسار من خاصية `img` لكل صنف في `js/app.js`.
- عند غياب أي صورة أو تعذّر تحميلها، تظهر أيقونة الصنف كبديل نظيف تلقائياً.
- لتغيير اسم ملف صورة، عدّل قيمة `img` للصنف المقابل في `js/app.js`.
- استخدم صوراً حقيقية للأطباق اليمنية فقط، وتجنب أي صور غير مطابقة.
